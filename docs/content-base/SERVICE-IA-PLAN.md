## Прототип

`prototype/index.html` (208 КБ, self-contained) — опубликован как артефакт.
Реализованы **все 6 вкладок** в двух темах с переключателем аудитории:

| Волна | Вкладки | Живая логика |
|---|---|---|
| Первая | Обо мне · Сегодня · Подобрать дату | скоринг мухурты с вето-потолками |
| Вторая | Совместимость · Практики · Справочник | ашта-кута (4 куты), садхана (стоп-факторы), фасетный каталог |

Данные встроены генератором `scratchpad/gen_protodata.py` из `data/*.json`:
27 накшатр (каталог + статьи), 14 групп глоссария, 4 металла, мантры, 9 катх планет.

Проверено в браузере: поиск «повозка» → 1, фасет «Луна» → 3, ганданта → 6,
ашта-кута Ашвини+Магха → 5/21 с нади-дошей, все 4 стоп-фактора садханы
исключают день, статья Рохини рендерит 12 секций, ошибок в консоли нет.

## Журнал

- **UX-аналитик ✅.** Backbone принят как основа, но 4 существенные правки: (1) «Сегодня» = дашборд-точка входа для вернувшегося пользователя, не рядовой хаб; (2) «Практики» распустить как топ-таб — мантры встроить в «Обо мне»/«Сегодня», садхану увести в проф-инструменты; (3) тара-бала — не вкладка, а сквозной модуль (в «Сегодня» и «Подобрать дату»); (4) режим «по Луне» без времени рождения — критичная продуктовая развилка (накшатра/панчанга доступны, лагна/дома/Карта блокируются с плашкой). Переименования: «Моя карта»→«Обо мне»(простая)/«Карта»(профи), «Когда лучше»→«Подобрать дату». Переключатель = один флаг audience, управляет и набором табов, и пресетом раскрытия секций; дефолт — простой; дисклеймеры видны обеим аудиториям. Флагманы прототипа: Обо мне, Сегодня, Подобрать дату (покрывают оба API + 3 калькулятора). Открытый риск: «Справочник» рискует стать свалкой — нужна внутренняя ИА.
- **Ведический астролог ✅.** Backbone доменно жизнеспособен, интент-хабы отражают реальные разделы джйотиш, Джанма-накшатра как якорь — корректный классический выбор. Блокирующие правки: (1) **панчангу дня собрать в единое целое** в «Сегодня» — 5 элементов (вара+титхи+накшатра+йога+карана) + стоп-факторы (Бхадра/Вишти, Вьятипата/Вайдхрити, Раху-калам) вместе, нельзя показывать «накшатра хорошая» умолчав активную Бхадру; разделять можно только «панчанга-на-дату» (расчёт) vs «панчанга-справочник» (энциклопедия); (2) **совместимость пометить как частичную** (21/36, ашта-кута ≠ полная мелапака — нет Мангала-доши/бхакут), «ориентир, не приговор»; (3) **вывести дисклеймеры** из disclaimers.json у всех не-verified результатов, event-picker — явно «оценочная модель без Раху-калама». Важные: тара-бала в «Подобрать дату» = фактор скоринга (вес 4), не отдельный вердикт; даши держать в «Моя карта» (натал), не выносить; «Моя карта» держит Лагну наравне с Джанма-накшатрой; пады в профи связать с навамшей D9. Этика (обязательно в простой версии): здоровье/болезни, «неблагоприятные» дни, нади-доша, Сад-сати, ганданта — переформулировать из «приговора» в «зона внимания». Дал двухуровневый словарь 13 терминов (профи-санскрит → новичок). Оговорки к расчётам: Whole Sign дома, достоинство по знаку без градуса, ретро в API нет, йони-кута упрощена, правило 27-й спорно (школы: 22/23).
- **Проектировщик ✅.** Поэкранные вайрфреймы всех 6 хабов с пометками [П]/[Про], карта соответствия всех ~19 плоских разделов HTML → 6 хабов (ничего не потеряно). Библиотека из ~24 переиспользуемых компонентов (BirthForm, NakshatraCard, ChipFilter, VerdictBlock, ScoreBreakdown, LagnaChart SVG, PadaWheel SVG, MantraBlock, TaraChakraTable, PanchangaCard, KutaBreakdown, DisclaimerPanel, ModeSwitch, TOCSidebar…). Форма рождения: дата обязательна, место→координаты→/api/tz→часовой пояс, чекбокс «время неизвестно» затеняет лагну/карту но оставляет накшатру. Навигация: desktop верхняя 6 вкладок + ModeSwitch справа; mobile нижний таб-бар 5 + «Ещё»; режим управляет глубиной, проф-подвиды со «звёздочкой». Полная таблица состояний (пусто/загрузка/ошибка/частичный ввод) для всех флагманов + адаптив (sticky-TOC→bottom-sheet, широкие таблицы→скролл, SVG→полная ширина+зум).
