## Критерии приёмки

- Все JSON валидны (`python3 -m json.tool`), кириллица не экранирована (`ensure_ascii=False`).
- Тексты перенесены дословно, без HTML-тегов (теги заменены на плоский текст).
- В каждом файле — поле `_source` с кратким указанием, откуда взято.
- README в `data/` дополнен новыми файлами.
