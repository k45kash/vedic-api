# Панчанга v2

Маршрут разработки — `/panchang-day-v2`. Контроль для сверок — Ставрополь, 27.11.2026, 03:00, UTC+3, видимые положения. Сравнение ведётся с `/panchang-day?date=2026-11-27&time=03:00`. Эталонную страницу и её API-контракт сохраняем.

| Задача | Критерий приёмки |
|---|---|
| Шкала | Один маркер с временем, активные интервалы выделены. Выбор минуты мышью, касанием и клавиатурой. |
| Сводка | Пять элементов и ближайший переход среди них видны до шкалы. Для перехода с секундами выбирается первая целая минута в новом интервале. |
| Мобильный вид | Горизонтальная прокрутка с закреплёнными названиями рядов; дополнительные ряды и карта раскрываются по запросу. |
| Раху-кала и Абхиджит | Полные интервалы сохраняются, пересечения выделены отдельно. |
| Календарь месяца | Титхи и накшатра на восходе, признак Бхадры в местные гражданские сутки. Клик открывает дату. |
| Ссылка для сверки | Передаёт город, координаты, выбранные дату, минуту, смещение и режим. |
| Часовые пояса | Проверяем смещение по городским координатам и дате. Точный расчёт суток перевода часов требует API с зоной IANA и хранением границ в UTC. |
| Оценки | Отображаем действующие справочники. Разницу с коллегами по Тритии и трактовку пересечения Абхиджит сверяем отдельно. |

## Журнал

1. Определены маршрут, контрольный пример и критерии проверки.
2. Реализованы маршрут v2, единый маркер, сводка, переход к ближайшей смене элементов, мобильные раскрывающиеся ряды и D1. Добавлены пересечения Раху-калы с Абхиджит, ссылка с параметрами и месячный API.
3. Браузерная проверка. На 03:00 ближайший переход — 07:19:03, Тритья → Чатуртхи и Вишти → Бава. Кнопка ставит 07:20, первую целую минуту после границы. В календаре 27 ноября видны Чатуртхи, Ардра и Бхадра. Ссылка содержит параметры контрольного примера. На ширине 390 px проверены раскрытие дополнительных рядов и загрузка D1.
4. Контроль исходной страницы выполнен побайтовым сравнением с опубликованным коммитом 73c3e3d. v2 собрана для локального просмотра. На Railway опубликован эталон.
5. В работе остаются переходы на летнее и зимнее время и сверка трактовок. Автоматический режим пока берёт смещение на местный полдень выбранной даты, применяет его ко всем суткам и к отображаемому месяцу. Трактовки сверяем после получения правил от коллег.
6. v2 опубликована на Railway из коммита 1545580. На стенде проверены дневная сводка, D1, календарь ноября и доступность эталонной страницы.
7. Реализован расчёт гражданских суток по зоне IANA. API в автоматическом режиме возвращает границы суток в UTC и интервалы с местным смещением. Календарь месяца использует отдельные границы для каждой даты. Ручной режим использует фиксированное UTC-смещение. Эталон обращается к прежнему контракту с фиксированным смещением.
8. Проверено в API и браузере. В Берлине 29 марта 2026 сутки длятся 23 часа, при открытии ссылки на пропущенные 02:30 отображается 03:00 с пояснением. 25 октября сутки длятся 25 часов. Оба вхождения 02:30 можно выбрать, а ссылка хранит конкретный момент в UTC. Границы всех рядов Ставрополя на 27 ноября совпали с эталоном. Сборка прошла, 419 тестов прошли и два дали ожидаемый сбой.
9. Дополнение доступно локально. Сверка трактовок Тритии и Абхиджит остаётся открытой, пока нет правил, которыми пользуются коллеги.
10. Для сверки добавлены пояснения к оценке Тритьи в двух пакшах и расчёт интервала Абхиджит вне Раху-калы. Расчёт явно показывает полное окно, пересечение и остаток. Оценка Тритьи соответствует текущему справочнику проекта. Правило коллег остаётся предметом сверки.
11. Изменения опубликованы на Railway из main (1bb1347). API вернул 25-часовые сутки для Берлина. В браузере на примере Ставрополя проверены пояснение к Тритье и окно Абхиджит вне Раху-калы 11:59–12:17.
12. Добавлено расписание «Переходы дня». В нём собраны пять элементов панчанги, восход, закат и границы Раху-калы и Абхиджит. Одновременные изменения собраны в одной строке. На сутках перевода часов время события подписано со смещением UTC. Кнопка времени выбирает первую целую минуту после события. Расписание свёрнуто при открытии страницы.
13. Расписание развёрнуто на Railway из main (a2749c9). На стенде для Ставрополя титхи и карана сгруппированы в 07:19:02. Выбор этого события обновляет сводку и D1 на 07:20. Локальный контрольный расчёт ранее возвращал 07:19:03.
14. В публичном меню и в кабинете «Панчанга» открывает v2. Для прежней страницы есть отдельный пункт «Эталон» в публичном меню и «Панчанга · эталон» в кабинете. При переключении через публичное меню переносятся дата и время из адреса страницы. Ссылка «Эталон для сверки» внутри v2 передаёт выбранные дату и время. На узком экране публичное меню прокручивается горизонтально.
15. Навигация опубликована на Railway из main (7cc1980). В браузере проверен переход из эталона в v2 и обратно для 27.11.2026, 03:00.
16. Панчанга перенесена в кабинет как единственная версия интерфейса. Старые адреса /panchang-day и /panchang перенаправляют на v2 с параметрами ссылки. Гостя отправляем на вход и возвращаем к расчёту после авторизации. Дневной и месячный API требуют действующую учётную запись. Общий /api/panchang сохраняет прежний контракт. Эталонный расчёт проверяется тестами в режиме фиксированного смещения.
