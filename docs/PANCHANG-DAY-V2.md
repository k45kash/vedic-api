# Панчанга v2

Маршрут разработки — `/panchang-day-v2`. Контроль для сверок — Ставрополь, 27.11.2026, 03:00, UTC+3, видимые положения. Сравнение ведётся с `/panchang-day?date=2026-11-27&time=03:00`. Эталонную страницу и её API-контракт сохраняем.

| Задача | Критерий приёмки |
|---|---|
| Шкала | Один маркер с временем, активные интервалы выделены. Выбор минуты мышью, касанием и клавиатурой. |
| Сводка | Пять элементов и ближайший переход среди них видны до шкалы. Для перехода с секундами выбирается первая целая минута в новом интервале. |
| Мобильный вид | Горизонтальная прокрутка с закреплёнными названиями рядов; дополнительные ряды и карта раскрываются по запросу. |
| Раху-кала и Абхиджит | Полные интервалы сохраняются, пересечения выделены отдельно. |
| Календарь месяца | Титхи и накшатра на восходе, признак Бхадры в местные гражданские сутки. Клик открывает дату. |
| Ссылка для сверки | Передаёт город, координаты, выбранные дату, минуту, смещение и режим. |
| Часовые пояса | Проверяем смещение по городским координатам и дате. Точный расчёт суток перевода часов требует API с зоной IANA и хранением границ в UTC. |
| Оценки | Отображаем действующие справочники. Разницу с коллегами по Тритии и трактовку пересечения Абхиджит сверяем отдельно. |

## Журнал

1. Определены маршрут, контрольный пример и критерии проверки.
2. Реализованы маршрут v2, единый маркер, сводка, переход к ближайшей смене элементов, мобильные раскрывающиеся ряды и D1. Добавлены пересечения Раху-калы с Абхиджит, ссылка с параметрами и месячный API.
3. Браузерная проверка. На 03:00 ближайший переход — 07:19:03, Тритья → Чатуртхи и Вишти → Бава. Кнопка ставит 07:20, первую целую минуту после границы. В календаре 27 ноября видны Чатуртхи, Ардра и Бхадра. Ссылка содержит параметры контрольного примера. На ширине 390 px проверены раскрытие дополнительных рядов и загрузка D1.
4. Контроль исходной страницы выполнен побайтовым сравнением с опубликованным коммитом 73c3e3d. v2 собрана для локального просмотра. На Railway опубликован эталон.
5. В работе остаются переходы на летнее и зимнее время и сверка трактовок. Автоматический режим пока берёт смещение на местный полдень выбранной даты, применяет его ко всем суткам и к отображаемому месяцу. Трактовки сверяем после получения правил от коллег.
