# Дизайн-система сервиса

Тёмная тема — существующая «звёздная» (из исходного HTML, токены в `data/design_tokens.json`).
Светлая — спроектирована по ролям как тёплый «пергамент», не стерильно-белая, чтобы сохранить
книжно-ведическую интонацию. Обе темы переключаются пользователем (независимо от переключателя
аудитории Пользователь/Астролог).

Решения по открытым вопросам (приняты пользователем):
1. **Границы** — два токена: `--line` (декоративный, тонкий) + `--line-strong` (функциональный,
   ~3:1) — усиление только там, где рамка реально разделяет (поля, таблицы, ячейки карты).
2. **Глифы планет/знаков** — единый SVG-набор вместо юникод-символов (кросс-платформенная ровность).
3. **Тон дисклеймеров** — мягкий для этически чувствительного контента (см. §4).
4. **Две темы** — тёмная + светлая с переключателем (см. §1).

## 1. Токены цвета — обе темы

Компоненты читают **семантические роли**, а не сырые hex. Ниже — таблица ролей с значениями
для обеих тем. Контрасты подобраны под WCAG AA (текст ≥4.5:1, крупный/границы ≥3:1).

| Роль | Тёмная | Светлая | Назначение |
|---|---|---|---|
| `--surface-base` | `#0a0c12` | `#efe7d5` | фон страницы |
| `--surface-raised` | `#12151f` | `#f6f0e2` | панели, шапки таблиц, hover-подложка |
| `--surface-raised-2` | `#171b28` | `#f1e9d8` | вложенные поверхности |
| `--surface-card` | `#161a27` | `#fdfbf4` | карточки, инпуты, чипы |
| `--surface-translucent` | `rgba(18,21,31,.6)` | `rgba(253,251,244,.7)` | плавающие подложки (легенда, sticky) |
| `--line` | `#282d3e` | `#d9cfb6` | декоративные разделители (тонко) |
| `--line-strong` | `#3a4055` | `#b7a682` | функциональные границы: поля, сетки таблиц, ячейки карты, сегменты |
| `--border-accent` | `#b8923a` | `#a9822f` | рамка важных панелей (`.tool`) |
| `--text-primary` | `#e9e2d2` | `#262019` | основной текст |
| `--text-secondary` | `#a89c84` | `#6d6553` | подзаголовки, мета |
| `--text-tertiary` | `#6f6753` | `#9a9179` | **только** крупное/декор/disabled (не для основного текста — не проходит AA) |
| `--accent` | `#dcb45c` | `#9c7016` | ссылки, крупные значения, ключевой акцент |
| `--accent-heading` | `#b8923a` | `#8a6412` | uppercase-заголовки секций, номера |
| `--accent-soft` | `#e8cd86` | `#b8923a` | заголовки h3 инструментов |
| `--accent-warm` | `#e08b3e` | `#c06a1a` | шафрановые акцентные ссылки |
| `--sem-good` | `#8fb27a` | `#4f7a3f` | благоприятно (текст/иконка) |
| `--sem-bad` | `#c76b7a` | `#a83f52` | неблагоприятно |
| `--sem-neutral` | `#7fa8c9` | `#3f6f96` | смешанно/нейтрально |

Заливки семантических чипов — тот же цвет с альфой: good `.12`, bad `.10`, neutral `.10`
(в обеих темах от соответствующего `--sem-*`).

**Домены цвета** (планеты/стихии/группы домов) — категориальные шкалы, единые в обеих темах,
но в светлой затемняются на ~15–20% для контраста на светлом фоне. Канон стихий — `ELEM_COL`
(Огонь `#d8624a`, Земля `#8fb27a`, Воздух `#7a9ec7`, Вода `#6a8fc7`); садхановый набор — только
внутри блока садханы. Планеты — `ui_colors.json` (единый источник).

**H1-градиент:** тёмная — `linear-gradient(180deg,#f2dc98,#c1963c)`; светлая —
`linear-gradient(180deg,#b8923a,#8a6412)` (темнее, чтобы читался на пергаменте).

**Звёздный фон:** тёмная — canvas 170 звёзд, opacity .45 (в проф-режиме .25); светлая —
звёзды **скрыты**, вместо них едва заметная бумажная текстура/чистый фон (метафора «дневного
неба»). Переключение темы гасит/зажигает canvas.

### Реализация переключения

`:root` — тёмная по умолчанию (сохраняем текущую эстетику как «родную»). Атрибут
`:root[data-theme="light"]` переопределяет роли на светлые значения. Выбор темы «липкий»
(localStorage), уважает `prefers-color-scheme` при первом визите. Все компоненты используют
только `var(--...)` — тем переключается одним атрибутом, без правок разметки.

## 2. Типографика

Сериф Iowan Old Style / Palatino / Georgia для контента — в обеих темах. Иерархия строится
**разрядкой (letter-spacing) + uppercase**, а не размером (фирменный приём — сохранить).

| Уровень | Размер | Приём | Токен цвета |
|---|---|---|---|
| Display / H1 | `clamp(40px,7vw,66px)`, ls 2px | золотой градиент (см. §1) | — |
| Eyebrow | 11px, ls 5px, uppercase | максимальная разрядка | `--accent-heading` |
| H2 инструмента | 26px, weight 400 | спокойный сериф | `--accent-soft` |
| Заголовок секции | 11–13px, ls 2–3px, uppercase | | `--accent-heading` |
| Body | 14.5px, lh 1.62 | абзацы | `--text-primary` |
| Body-secondary | 13.5px | | `--text-secondary` |
| Lede / вводка | ~16px | увеличенный вводный | `--text-primary` |
| Meta / бейдж | 11px, ls 1–1.5px | | по контексту |

**Числовые проф-таблицы** (градусы, скоры, координаты) — служебный tabular-стек
(`ui-monospace, "SF Mono", Menlo, monospace`, `font-variant-numeric: tabular-nums`), заголовки
таблиц остаются серифом. Сериф — для повествования, tabular — для расчётов. Тело таблиц не ниже
12px; `--text-tertiary` для текста не использовать.

Две насыщенности: 400 и «полужирный» акцент через цвет/разрядку, не через тяжёлые weights.

## 3. Границы (детализация решения #1)

- `--line` — декоративные разделители, рамки карточек-контента: оставить тонкими; на них держится
  «тихая, дорогая» эстетика. Карточка накшатры, разделители блоков — здесь `--line`.
- `--line-strong` — там, где граница несёт функцию разделения и её отсутствие ломает понимание:
  контур полей ввода, линии сетки таблиц (наватара-чакра, ашта-кута, 30 мухурт), грани ячеек
  SVG-карты домов, сегменты переключателя. Здесь `--line-strong`.

Правило: если убрать границу и структура перестаёт читаться — это `--line-strong`. Если граница
просто украшает — `--line`.

## 4. Тон дисклеймеров — мягкий (решение #3)

Этически чувствительный контент подаётся как «зона внимания / тема роста», не как приговор.
Пометки достоверности (`disclaimers.json`) выводятся под результатами обеих аудиторий; в простом
режиме — короче, в профи — с провенансом. Ниже — эталонные мягкие формулировки (заменяют сухие
«серьёзное препятствие / неблагоприятно / болезни»):

| Контекст | Мягкая формулировка |
|---|---|
| Сад-сати | «Период Сатурна (Сад-сати) — время взросления, дисциплины и переоценки. Это не наказание, а этап, который проходят многие и выходят окрепшими.» |
| Нади-доша | «Совпадение нади — фактор, на который в традиции обращают внимание. Это не запрет на союз, а повод отнестись вдумчиво; при желании есть традиционные средства (упайи). Полную картину даёт астролог.» |
| «Неблагоприятный» день / тара | «День осторожности — лучше не начинать крупное. Сила таких дней в дальних кругах ослабевает, так что это мягкая рекомендация, а не запрет.» |
| Здоровье / доша | «Аюрведическая конституция и склонности — это типология, а не диагноз. Не заменяет консультацию врача.» |
| Ганданта | «Ганданта — точка глубокой трансформации; тема роста через переходы, а не приговор.» |
| Оценочная модель (подбор события, тара по школе) | «Это ориентир по методу школы, а не окончательный вердикт — точный расчёт делает астролог по всей карте.» |
| Частичный расчёт (ашта-кута) | «Быстрая оценка по 4 признакам из 8 — ориентир, не приговор. Полная совместимость учитывает всю карту.» |

Принцип тона: тепло, без драматизации, с выходом на действие/следующий шаг (упайя, консультация),
без «обратного отсчёта до беды». Легенда меток («классика / школы расходятся / реконструкция»)
доступна, но не пугает.

## 5. Глифы планет и знаков (решение #2)

Единый **SVG-набор** вместо юникод-символов (☉ ♈ рендерятся неровно по шрифтам и платформам):
- 9 планет: Солнце, Луна, Марс, Меркурий, Юпитер, Венера, Сатурн, Раху, Кету;
- 12 знаков зодиака.

Требования: один визуальный вес (единая метрика/толщина линий), масштабируемость (в SVG-карте
домов, круге пад, инлайн в тексте), окраска через `currentColor` / токен цвета планеты
(`ui_colors.json`). Хранить как один встроенный SVG-спрайт (`<symbol>` + `<use>`).

Разделение классов символов:
- **доменные глифы** (планеты/знаки/узлы, ретро ℞) — цветные, часть контента, из спрайта;
- **UI-иконки** (навигация, фильтр, поиск, свернуть) — отдельный тонкий линейный набор, монохром;
- **маркеры статуса** (good/bad ✓✕, достоверность, ганданта) — из линейного набора, не эмодзи.

Эмодзи-события (33 из `events_muhurta.json`) — в простой версии как дружелюбный акцент, в профи
заменяются линейными иконками.

## 6. Плотность: простая vs профи (ортогонально теме)

Тема (свет/тьма) и аудитория (простой/профи) — независимы. Плотность задаёт аудитория:

| Параметр | Простая | Профи |
|---|---|---|
| padding карточек | 18–20px | 12px |
| межблочный gap | 24–28px | 12–16px |
| радиус карточек | 14–15px | 11–12px |
| размер тела | 14.5px | 13.5px, числа 12px tabular |
| подача | один ответ на экран, детали под «Подробнее» | таблицы, всё сразу |
| звёздный фон (тёмная тема) | opacity .45 | .25 |

## 7. Переключатели в шапке

Два независимых контрола:
- **Тема** — иконка-кнопка (солнце/луна), переключает `data-theme`. Компактно, слева от аудитории.
- **Аудитория** — сегмент-контрол [Пользователь | Астролог], «липкий», активный сегмент с
  золотым акцентом (`--accent` фон-альфа + рамка `--accent-heading`).

На mobile оба уезжают в меню профиля. Смена любого — короткий кроссфейд (.2s), контекст сохраняется.

## Открытые вопросы

- Источник SVG-глифов: взять готовый астрологический набор (напр. Astronomicon) или отрисовать
  свой под толщину линий темы — уточнить при сборке.
- Светлая тема для SVG-карты домов: цвета групп домов на светлом фоне требуют проверки контраста
  заливок (сейчас рассчитаны под тёмный) — доработать при первой сборке карты.
