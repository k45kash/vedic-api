### Требует твоих действий 🔒

| Что | Где | Зачем |
|-----|-----|-------|
| Сервис MongoDB + **Volume на `/data/db`** | Railway | без вольюма данные стираются при редеплое |
| `MONGODB_URI`, `MONGO_DB`, `JWT_SECRET` | Railway → сервис API | подключение и подпись токенов |
| Почтовый отправитель (SMTP или сервис рассылок) | — | письма подтверждения и сброса пароля |
| Приложение Yandex OAuth | oauth.yandex.ru | `YANDEX_CLIENT_ID` / `SECRET` |
| Приложение VK ID | VK для разработчиков | `VK_CLIENT_ID` / `SECRET` |
| Бот через @BotFather + привязка домена | Telegram | `TELEGRAM_BOT_TOKEN` / `USERNAME` |

`JWT_SECRET` сгенерировать: `openssl rand -hex 32`

#### Пошагово: MongoDB на Railway

1. В проекте Railway нажать **`+ New`** (или `⌘K` → «Database») → выбрать **MongoDB**.
   Поднимется официальный Docker-образ Mongo.
2. **Проверить вольюм.** Открыть сервис Mongo → вкладка с вольюмами. Если вольюма нет —
   создать: `⌘K` → «Volume» (или правый клик по канвасу) → выбрать сервис Mongo →
   mount path **`/data/db`**. Без этого база стирается при каждом редеплое.
3. Строку подключения прописывать **не нужно**: Mongo-сервис сам публикует `MONGO_URL`,
   приложение его понимает. Достаточно убедиться, что оба сервиса в одном проекте.
4. На сервисе **API** добавить переменные: `JWT_SECRET` (обязательно) и при желании
   `MONGO_DB=vedic` (по умолчанию и так `vedic`).
5. Для локальной разработки — скопировать публичную строку подключения из
   Mongo → Variables в свой `.env` как `MONGODB_URI` (внешний доступ идёт через
   TCP Proxy, включён по умолчанию).
