`PycharmProjects/Vedic` не сделан:

| Эндпоинт | Что даст | Статус |

| `/api/panchang` | титхи, мухурты, хоры за период | ⛔ панчанга дня захардкожена |
| `/api/calendar` | транзиты Луны по накшатрам | ⛔ 12 демо-дней в подборе даты |
| `/api/tz` | часовой пояс по координатам | ⛔ формы рождения нет вообще |
| `/api/sade-sati` | периоды Сатурна | ⛔ не заложено в IA |

Адаптеры `calculators/api-adapter.ts` написаны и типизированы, но никем не вызываются.

## Что доработать — по приоритету

**1. Подключить API** (снимает главное ограничение)
Форма рождения → `/api/horoscope` → профиль в сторе → «Обо мне», тара, подбор даты
начинают работать на реальных людях и датах. Плюс режим «по Луне» без времени рождения.

**2. Собрать панчангу из данных** (`panchanga.json`)
Вывести все 5 элементов + **стоп-факторы** (дневные и комбо) — блокирующее требование
астролога, сейчас имитировано текстом.

**3. Развернуть подбор даты на все 33 события** (`events_muhurta.json`)
Логика уже написана и протестирована — нужно просто перестать хардкодить 7 событий.

**4. Достроить «Карту»** (`chart.ts` + `houses/signs/placements/chart_geometry`)
Реальная раскладка планет по домам с трактовками и настоящей геометрией SVG
вместо нарисованного «на глаз» квадрата.

**5. Вывести `planet_in_nakshatra.json`** — 243 трактовки одной секцией в статье (проф).

**6. Подключить тексты из данных** (`disclaimers.json`, `ui_texts.json`)
Сейчас дисклеймеры и просветительские тексты дублируются в разметке — при правке
контента придётся править код.

**7. Проф-глубина**: `yogakarma.json` (аспекты/даши), `muhurta30.json` (30 мухурт),
`retrograde.json`, наватара-чакра из `tara_school.json` + `tara_dana.json`.

**8. Дозаполнить кутовый расчёт** — 4 недостающие куты (Варна, Вашья, Граха-майтри,
Бхакут = 15 баллов) требуют знак Луны, который API отдаёт. Даст полные 36/36.

**9. Мелочи**: `sources.json` в отдельный раздел, `sign_short`/`sadhana_day_index`
при полной сборке, богатство `planet_stories` (108 имён, янтры, 3 катхи вместо 1).
