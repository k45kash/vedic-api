# Контент-база Астро-сервиса

Данные извлечены из `nakshatry_polnyy (14).html` (архив накшатр, собранный в одном HTML).
Все файлы — UTF-8 JSON, язык контента — русский (санскрит в IAST/деванагари внутри полей).

## Основной контент

| Файл | Содержимое |
|---|---|
| `nakshatras.json` | 27 накшатр, ~60 полей каждая: управитель, дэвата, символ, шакти, гана/варна/йони/доша, мантры, гаятри, даша, здоровье, профессии, совместимость, мухурта good/bad, упайи, катха, астрономия |
| `nakshatra_names.json` | 27 названий накшатр (порядок канонический, индекс 0 = Ашвини) |
| `padas.json` | все 108 пад (27 × 4) с описаниями |
| `planet_in_nakshatra.json` | 9 планет × 27 накшатр — трактовка планеты в стоянке (ключи «1»–«27») |
| `panchanga.json` | вара (дни недели), караны, йоги, особые йоги, стоп-факторы |
| `tithi.json` | 15 титх × 2 пакши, 5 категорий благоприятности |
| `events_muhurta.json` | 33 события (свадьба, бизнес, стрижка…) с подходящими накшатрами/титхи/днями |
| `muhurta30.json` | 30 мухурт дня (вара-мухурта) |
| `signs.json` | 12 знаков (раши) |
| `houses.json` | 12 домов (бхав) |
| `placements.json` | 9 планет × 12 домов и × 12 знаков — трактовки положений |
| `yogakarma.json` | аспекты, соединения, даши, антардаши |
| `retrograde.json` | ретроградность 9 грах |
| `planet_stories.json` | граха-катхи — истории 9 планет + гимн Наваграха |
| `mantra_upaya.json` | мантры-упайи |
| `sadhana.json` | изделия для садханы: 4 металла, логика выбора дня |
| `glossary.json` | глоссарий: 14 групп, 38 терминов |
| `tara_school.json` | школа тара-балы: детали по 9 тарам |
| `sources.json` | источники и благодарности |

## Тексты интерфейса

| Файл | Содержимое |
|---|---|
| `disclaimers.json` | 15 дисклеймеров достоверности (.needs-check) по разделам — тип verified/model/needs-check + легенда пометок из шапки («классика», «школы расходятся», «реконструкция / не уверен») |
| `ui_texts.json` | просветительские тексты, зашитые в JS/разметку (нет в остальных JSON этой папки): шапка (eyebrow/h1/subtitle/lede), «Астрономия накшатр» (5 фактов), три группы тар + правило 27-й накшатры, мнемоника тары по Виншоттари, примечания ашта-куты, вводные абзацы разделов (тара, чакра, подбор события, карта Лагны, аспекты/периоды, панчанга, пады и др.) |

## Таблицы калькуляторов

| Файл | Содержимое |
|---|---|
| `tara_bala.json` | 9 тар (Джанма…Ати-митра): качество, описание. Расчёт: `pos = ((day − janma) mod 27) + 1`, тара = `(pos − 1) mod 9`, группа = 1/2/3 по девяткам |
| `tara_dana.json` | пожертвования (дана) по 9 тарам |
| `nak_rulers_seq.json` | последовательность управителей Вимшоттари (Кету → Меркурий), цикл по 9 |
| `nak_ruler_short.json` | краткие обозначения управителей |
| `picker_weights.json` | веса скоринга подбора события: тара 4, накшатра 3, титхи 2, день 2, йога 1 |
| `gandanta_padas.json` | гандантовые накшатры (№ 1, 9, 10, 18, 19, 27) |
| `sadhana_day_index.json` | индексы дней недели для расчёта садханы |
| `sign_short.json` | краткие названия знаков |
| `ui_colors.json` | цвета планет/управителей/стихий из исходного UI |

## Геометрия и UI-спецификации

| Файл | Содержимое |
|---|---|
| `chart_geometry.json` | геометрия карт: северный стиль (12 полигонов NI_GEOM + центры подписей, viewBox 360×360), южный стиль (сетка 4×4, ячейка 90, центральный прямоугольник 90,90,180,180), колесо пад (cx/cy 340, радиусы 330/290/248/150, шаг 360/108) |
| `filter_defs.json` | спецификация фильтров каталога накшатр: 8 фасетов (primary: управитель, тип; остальные под «Ещё фильтры»), правило нормализации ganaBase, флаг «⚠ Гандантовые (6)», текстовый поиск по 14 полям |
| `design_tokens.json` | дизайн-токены темы: :root-палитра (ink/bg/panel/gold/…), JS-цветмапы (стихии, группы домов, планеты по слагам, RULER_COL_PADA, SADHANA_ELEM_COL), типографика (Iowan Old Style/Palatino, uppercase-заголовки), многослойный radial-gradient фон, паттерны (радиусы, карточки, бейджи, sticky-TOC), параметры звёздного канваса (170 звёзд, opacity .45) |

## Примечания

- В исходном HTML нет астрономических расчётов — все калькуляторы работали от ручного ввода. Эти данные — справочный слой; расчётный слой (накшатра/панчанга по дате) даёт отдельное API.
- Скрипт извлечения: `extract_data.py` (парсит JS-константы из HTML; при обновлении HTML можно перегенерировать).
